# Java 程序设计课程作业

七次作业分别保存在 homework-01.zip 至 homework-07.zip 中。下载对应压缩包并解压即可查看 .java 源文件；各作业独立编译，第六次作业各子目录也独立编译，避免同名类冲突。

1. 环境搭建与 HelloWorld
2. 第一、二章基础练习
3. 第五章循环练习
4. 第七章数组练习
5. 正则表达式上机测试
6. 第九章课本例题
7. 第九章一星练习与 UML 类图

使用 JDK 11。第六次作业的 Point2D 示例附有 JavaFX 依赖。教材例题与练习来源：梁勇《Java语言程序设计与数据结构（基础篇）》，机械工业出版社，2018。
